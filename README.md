# FeedSense (MV3 scaffold)

Initial TypeScript-oriented scaffold for a Chrome MV3 extension that filters and summarizes Facebook feed units.

## Structure

- `src/content`: DOM location, extraction, observation, and decision application.
- `src/background`: policy engine, message routing, cache, settings.
- `src/options`: minimal options page.
- `src/shared`: contracts for signals, settings, and messaging.
- `src/manifest.json`: extension manifest.
